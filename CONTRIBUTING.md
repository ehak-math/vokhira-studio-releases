# Contributing to Vokhira Studio

Thank you for your interest in helping improve Vokhira Studio!

---

## 1. Repository Scope & Contribution Policy

Please note that this repository (`ehak-math/vokhira-studio-releases`) is a **binary distribution, documentation, and community issue tracking repository**.

- The core application source code is maintained in a private repository (`ehak-math/vokhira-studio`).
- **We cannot accept source-code Pull Requests for the application core in this repository.**
- Pull requests submitted here should be limited strictly to repository documentation improvements (e.g., spelling fixes, clarification in markdown guides).

---

## 2. How You Can Contribute

Even without direct code contributions to the private application, community involvement is vital:

### 🐛 1. Testing and Reporting Bugs
Finding edge-case issues in Chinese transcription, audio alignment, subtitle rendering, or Windows compatibility helps make Vokhira Studio robust.
- Submit bug reports via our [Bug Report Template](https://github.com/ehak-math/vokhira-studio-releases/issues/new?template=bug_report.yml).
- Follow our [Support Guide](SUPPORT.md) to ensure your report includes actionable reproduction steps.

### 💡 2. Suggesting Features & Workflow Enhancements
If you have workflows, shortcuts, or features that would speed up your translation or dubbing process:
- Submit ideas via our [Feature Request Template](https://github.com/ehak-math/vokhira-studio-releases/issues/new?template=feature_request.yml).
- Explain your specific use case and how the enhancement benefits other creators.

### 📖 3. Improving Documentation
Clear installation guides and troubleshooting steps help new creators get started smoothly:
- If you spot an error, unclear instruction, or outdated link in any `.md` file, feel free to open a Pull Request against this repository.

---

## 3. Issue Guidelines

When opening an issue:
1. **Search first**: Ensure a similar issue does not already exist.
2. **Be specific**: Provide detailed context, exact Windows versions, and complete steps.
3. **Protect privacy**: **Never** include private API keys, sensitive personal information, or private client video files in issues.

---

## 4. Code of Conduct

We are committed to providing a friendly, respectful, and inclusive environment.
- Treat fellow community members and maintainers with courtesy and professionalism.
- Constructive feedback is welcome; derogatory or abusive behavior will not be tolerated.

Thank you for contributing to Vokhira Studio!
